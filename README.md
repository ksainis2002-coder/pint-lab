# Pint Lab

A recipe app for ice cream machines like the Johnson Velvet Creme and Ninja Creami: ice cream,
gelato, frozen yogurt, milkshakes, slushies, Italian ice and frozen drinks, with no gums or
pudding mix. Every recipe has a lean version, full macros and a step-by-step cooking mode.

The whole app is `index.html`. `manifest.webmanifest`, `sw.js` and the icons make it installable
on a phone and usable offline.

## Publish with GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → branch `main`, folder `/ (root)` → Save.
The app is then served at `https://<user>.github.io/pint-lab/`.

## Install on a phone

Open the address in Chrome (Android) or Safari (iPhone), then choose **Install app** or
**Add to Home Screen**.

Recipes are home versions inspired by store-bought flavors. Not affiliated with any brand named.
